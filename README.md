## 项目简介

灵感邮票是一个以文学与人文摘录为内容的沉浸式阅读网站。项目目前收录了来自 16 本书的 116 段文字，并把它们设计成一枚枚可以被发现、阅读和继续翻阅的“邮票”。

访客不需要先选择分类，也不需要注册账号：从首页挑选一枚邮票，进入阅读页后继续点击，就能让偶然遇见的一句话成为通往下一本书的小门。

## 为什么做这个项目

很多时候，我们不是因为一篇完整书评决定读一本书，而是先被其中的一句话击中。

但在常见的摘录列表和信息流里，文字很容易变成又一条被快速划过的内容。我想尝试一种更慢、更专注的阅读方式：减少菜单、搜索和推荐标签，把注意力留给文字本身，同时保留随机发现带来的惊喜。

“邮票”既像一段被保存下来的阅读片段，也像一封寄往下一次阅读的信。这是项目名称和视觉形式的由来。

## 功能亮点

- **116 枚摘录邮票**：每枚邮票包含摘录、作者和书名，并在有资料时标注章节。
- **随机发现**：首页每次展示来自 5 本不同书籍的邮票；阅读过程中通过按书分池和最近书目冷却机制，降低同一本书频繁连续出现的概率。
- **低门槛交互**：点击或轻触阅读区域即可查看下一张邮票，无需复杂导航。
- **渐进式图片加载**：首页使用 `512 × 768` WebP 预览图，进入阅读页后按需加载 `1024 × 1536` PNG 原图，在兼顾首屏速度的同时保留阅读画质。
- **可靠切换**：候选图片完成下载和解码后，图片、页码与文本状态才会一起更新；慢速网络下不会出现页码已经变化、图片仍停留在上一张的错位。
- **多端适配**：支持桌面和移动端布局；桌面端还可以使用 `→` 切换下一张、使用 `Esc` 返回首页。

## 使用说明

1. 打开[在线网站](https://for-inspiration.pages.dev/)。
2. 在首页选择任意一枚邮票。
3. 点击或轻触阅读区域，继续阅读下一张。
4. 点击左上角“返回”回到首页，重新选择邮票。

## 技术实现

### 纯静态架构

项目使用原生 HTML、CSS 和 JavaScript 构建，不依赖前端框架、数据库、账号系统或后端服务。内容由 JSON 驱动，并部署在 Cloudflare Pages 上。

### 内容与图片生成流程

摘录内容可以从工作簿筛选并导入 `data/quotes.json`。Python 脚本使用 Pillow 将摘录、作者、书名和章节排版到邮票模板中，批量生成统一规格的 PNG 阅读原图。

### 加载性能

首页预览与阅读原图使用两套资源：首页分阶段加载轻量 WebP，用户选择邮票后才请求对应 PNG。阅读页会在后台准备有限数量的候选原图，并在离开阅读页时取消未完成的旧请求，避免无效下载持续占用带宽。

### 状态一致性

阅读页只提交已经完整解码的图片。图片地址、当前索引、页码和替代文本在同一次更新中完成，确保连续点击、慢速网络以及关闭后重新进入等情况下，界面仍保持一致。

## 技术栈

- HTML5 / CSS3 / Vanilla JavaScript
- JSON
- Python / Pillow / openpyxl
- Cloudflare Pages
